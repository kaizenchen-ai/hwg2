## 🎯 功能特色

1. **單字卡翻面記憶**：25 個必學單字（12 家人 + 10 職業 + 3 身高形容），支援 Web Speech API 真人英文語音朗讀。
2. **連連看配對遊戲**：Emoji 與英文單字即時拖曳／點擊連線配對。
3. **聽音辨字挑戰**：按喇叭聆聽發音，從提示中選出正確單字。
4. **隨堂測驗系統**：隨機 10 題選擇題，即時計分與評級回饋。
5. **iPad / 觸控最佳化**：大按鈕、自適應寬度、直覺觸控體驗。
